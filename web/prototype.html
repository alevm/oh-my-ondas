Breadboard Prototype v1

Full prototype #1 on two 830-point breadboards · October 2026 · draft for review

Why this layout: with the Audio Shield under the Teensy, pins 0–23 sit inside the shield sockets. Everything here uses the pins past the shield edge (24–41, 3.3V, G). All UI parts share one I2C bus (Wire2), the LCD uses SPI1, and the Audio Shield keeps Wire (18/19) to itself. The LCD board stays off the breadboard (lesson from the white-screen debugging).
Replaces the earlier layout (v0.3: pins 0–23, ESP32, NeoPixels, Diotronic BOM), which assumed every Teensy pin was reachable. Purchases now live on the BOM page; the old diagram is in the git history.
Draft: the firmware pin map in config.h and the assembly guide still describe the old plan. They get updated once this layout is approved. The Si4732 pinout is to be confirmed from the Skyworks datasheet before soldering.

Build order

  1. Rails and entry (board A rows 1–6). Measure 3.3 V on the rail.
  2. CAP1188 + OLED + LCD: the stack already verified, now in its final place. Run layer3_integration.
  3. ADS1115 + faders (Phase 4, layer4_faders).
  4. MCP23017 + nav + buttons, then Quad encoders with the EC11s (Phase 5).
  5. GPS on the STEMMA chain (Phase 6).
  6. MAX9814 mic → LINE-IN L, then the piezo buffer + MIC/PIEZO switch, then the Si4732 radio → LINE-IN R.
  7. Everything together: no I2C errors, clean audio. Then copy the layout 1:1 onto the Perma-Proto.
